# 4YOU Store - متجر فور يو 🛍️✨

![4YOU Store Banner](https://4you-stores.com/favicon.ico)

متجر إلكتروني متكامل لبيع المنتجات الفاخرة (عطور، مكياج، عناية بالبشرة) بتصميم عصري مستوحى من الماركات العالمية.

🌐 **رابط الموقع الحي:** [4you-stores.com](https://4you-stores.com/)

---

## 🌟 المميزات الرئيسية

- **تصميم فاخر وعصري:** واجهة مستخدم أنيقة مستوحاة من الماركات العالمية (Chanel, Dior).
- **دعم اللغتين (عربي/إنجليزي):** دعم كامل للاتجاهين (RTL/LTR) مع تبديل سلس.
- **لوحة تحكم متكاملة:** إدارة المنتجات، الطلبات، التصنيفات، الكوبونات، والإعدادات.
- **نظام سلة تسوق متقدم:** إضافة/إزالة المنتجات، حساب الإجمالي، وتطبيق الكوبونات.
- **دعم الدفع المتعدد:** الدفع عند الاستلام (COD) والدفع عبر بنك الكريمي.
- **نظام تقييم ومراجعات:** يمكن للمستخدمين تقييم المنتجات وإضافة مراجعات.
- **متوافق مع جميع الأجهزة:** تصميم متجاوب بالكامل (Responsive Design).
- **تطبيق ويب تقدمي (PWA):** إمكانية تثبيت المتجر كتطبيق على الهاتف.

## 🛠️ التقنيات المستخدمة

### الواجهة الأمامية (Frontend)
- **React 19** + **Vite**
- **TypeScript**
- **Tailwind CSS** (للتصميم)
- **Radix UI** + **Lucide Icons** (للمكونات والأيقونات)
- **Wouter** (للتوجيه Routing)
- **tRPC** (للاتصال بالخادم)

### الواجهة الخلفية (Backend)
- **Node.js** + **Express**
- **tRPC Server**
- **Drizzle ORM** (للتعامل مع قاعدة البيانات)
- **MySQL** (قاعدة البيانات)
- **Nodemailer** (لإرسال رسائل البريد الإلكتروني)

## 🚀 كيفية التشغيل محلياً (Local Development)

### المتطلبات الأساسية
1. Node.js (الإصدار 18 أو أحدث)
2. pnpm (مدير الحزم)
3. قاعدة بيانات MySQL (يمكن استخدام XAMPP)

### خطوات التثبيت

1. **استنساخ المستودع:**
   ```bash
   git clone https://github.com/BenSHaker10/4you-store.git
   cd 4you-store
   ```

2. **تثبيت الحزم:**
   ```bash
   pnpm install
   ```

3. **إعداد متغيرات البيئة:**
   قم بإنشاء ملف `.env` في الجذر وأضف المتغيرات التالية:
   ```env
   DATABASE_URL=mysql://root:@127.0.0.1:3306/product_store
   JWT_SECRET=your-secret-key-here
   VITE_APP_ID=4you-store
   PORT=3000
   ```

4. **إعداد قاعدة البيانات:**
   ```bash
   pnpm db:push
   ```

5. **إضافة البيانات التجريبية (اختياري):**
   ```bash
   node seed-data.mjs
   ```

6. **تشغيل خادم التطوير:**
   ```bash
   pnpm dev
   ```
   سيتم تشغيل الموقع على `http://localhost:3000`

## 📁 هيكل المشروع

```text
4you-store/
├── client/                 # الواجهة الأمامية (React)
│   ├── public/             # الملفات العامة (الصور، manifest، sw.js)
│   └── src/
│       ├── components/     # المكونات القابلة لإعادة الاستخدام
│       ├── contexts/       # سياقات React (Cart, Theme, Language)
│       ├── hooks/          # الخطافات المخصصة (Custom Hooks)
│       ├── i18n/           # ملفات الترجمة (عربي/إنجليزي)
│       ├── pages/          # صفحات الموقع (Home, Products, Admin...)
│       └── lib/            # مكتبات مساعدة (tRPC, utils)
├── server/                 # الواجهة الخلفية (Node.js/Express)
│   ├── _core/              # إعدادات الخادم الأساسية
│   ├── db.ts               # إعدادات قاعدة البيانات
│   ├── routers.ts          # مسارات tRPC (API)
│   └── security.ts         # إعدادات الأمان (Rate Limiting, Headers)
├── drizzle/                # ملفات Drizzle ORM (Schema, Migrations)
├── shared/                 # الملفات المشتركة بين العميل والخادم (Types, Constants)
└── package.json            # إعدادات المشروع والحزم
```
