# تعليمات الرفع المباشر إلى GitHub

هذه الملفات جاهزة ليتم دمجها في مشروعك ورفعها مباشرة. بمجرد الرفع، سيقوم **GitHub Actions** بتحديث الموقع تلقائياً.

---

## 1. استبدال الملفات الأساسية
قم بنسخ هذه الملفات واستبدالها في مشروعك:
- `index.html` ← استبدله في المجلد الرئيسي للمشروع.
- `public/robots.txt` ← ضعه في مجلد `public`.
- `public/sitemap.xml` ← ضعه في مجلد `public`.
- `src/locales/ar.json` ← استبدل ملف الترجمة العربية (تأكد من المسار الصحيح في مشروعك).
- `src/components/Footer.tsx` ← استبدل مكون الفوتر (تأكد من المسار الصحيح في مشروعك).

---

## 2. أوامر الرفع من الترمنال (Terminal)
افتح الترمنال في مجلد مشروعك ونفذ الأوامر التالية:

```bash
# 1. إضافة التعديلات
git add .

# 2. حفظ التعديلات مع رسالة
git commit -m "تحديث السيو والفوتر واللغة العربية"

# 3. الرفع إلى GitHub
git push origin main
```

---

## 3. التحقق من التحديث
1. اذهب إلى مستودعك على GitHub.
2. اضغط على تبويب **Actions**.
3. انتظر حتى ينتهي الـ Workflow (يتحول للون الأخضر).
4. افتح موقعك [4you-stores.com](https://4you-stores.com/) وستجد التعديلات ظهرت!
