# دليل تشغيل متجر 4 YOU محلياً (Localhost)

هذا الدليل يشرح كيفية تشغيل متجر 4 YOU على جهازك الشخصي، مع التركيز على تحسين الأداء والسرعة.

## المتطلبات الأساسية
قبل البدء، تأكد من تثبيت البرامج التالية على جهازك:

1.  **Node.js (الإصدار 18 أو أحدث):** يمكنك تحميله من [الموقع الرسمي لـ Node.js](https://nodejs.org/en/download/).
2.  **pnpm:** مدير حزم سريع وفعال. لتثبيته، افتح موجه الأوامر (PowerShell أو CMD) ونفذ الأمر:
    ```bash
    npm install -g pnpm
    ```
3.  **XAMPP (مع MySQL و Apache):** يوفر لك بيئة خادم ويب وقاعدة بيانات MySQL. يمكنك تحميله من [الموقع الرسمي لـ XAMPP](https://www.apachefriends.org/download.html).

## الخطوات

### **الخطوة 1: فك ضغط المشروع وفتح PowerShell**
1.  فك الضغط عن ملف `4you-store-v4.zip` الذي قمت بتحميله.
2.  ادخل إلى المجلد الناتج `product-store-local`.
3.  افتح نافذة PowerShell داخل هذا المجلد:
    *   في شريط العنوان الخاص بالمجلد، اكتب `powershell` واضغط Enter.

### **الخطوة 2: إعداد قاعدة البيانات (MySQL عبر XAMPP)**
1.  شغل برنامج **XAMPP Control Panel**.
2.  اضغط على زر **Start** بجانب **Apache** و **MySQL**.
3.  تأكد أن كلتا الخدمتين تعملان (يظهر اللون الأخضر بجانبهما).
4.  افتح متصفح الويب واذهب إلى: [http://localhost/phpmyadmin/](http://localhost/phpmyadmin/)
5.  من القائمة اليسرى، اضغط على **"New"** (جديد).
6.  في خانة **"Create database"** (إنشاء قاعدة بيانات)، اكتب: `product_store`.
7.  اضغط على زر **"Create"**.
    *   **ملاحظة:** لا تقم بإنشاء أي جداول يدوياً، المشروع سيقوم بذلك تلقائياً.

### **الخطوة 3: إعداد ملف البيئة (.env)**
1.  في مجلد `product-store-local`، ستجد ملفاً باسم `.env.example`.
2.  قم بإنشاء نسخة من هذا الملف وسمها **`.env`**.
    *   **مهم:** تأكد أن اسم الملف هو `.env` وليس `.env.txt`. إذا كنت لا ترى امتدادات الملفات، اذهب إلى `View` -> `Show` -> `File name extensions` في File Explorer.
3.  افتح ملف `.env` باستخدام المفكرة (Notepad) أو أي محرر نصوص، وتأكد من وجود المحتوى التالي:
    ```env
    DATABASE_URL=mysql://root:@127.0.0.1:3306/product_store
    JWT_SECRET=my-secret-key-for-4you-store-2025
    VITE_APP_ID=4you-store
    PORT=3000
    OWNER_OPEN_ID=admin_owner
    VITE_FRONTEND_URL=https://for4u.info
    ```
    *   لقد قمنا بتغيير `localhost` إلى `127.0.0.1` لتحسين الأداء.
4.  **احفظ الملف وأغلقه.**

### **الخطوة 4: تثبيت المكتبات وبناء الجداول وإضافة البيانات**
في نافذة PowerShell التي فتحتها في الخطوة 1، نفذ الأوامر التالية بالترتيب:

1.  **تثبيت المكتبات (قد يستغرق بعض الوقت):**
    ```powershell
    pnpm install
    ```
    *   انتظر حتى تظهر رسالة `Done`.

2.  **بناء الجداول في قاعدة البيانات:**
    ```powershell
    pnpm db:push
    ```
    *   إذا سألك `Do you still want to push changes?`، اختر **Yes** واضغط Enter.

3.  **إضافة المنتجات والبيانات التجريبية:**
    ```powershell
    node seed-data.mjs
    ```

### **الخطوة 5: تشغيل المتجر (وضع الإنتاج - الأسرع)**
للحصول على أفضل أداء وسرعة، قم ببناء المشروع وتشغيله كنسخة نهائية:

1.  **بناء المشروع (Build):**
    ```powershell
    pnpm build
    ```
    *   هذا الأمر سيقوم بتجميع وضغط جميع ملفات المشروع لتكون جاهزة للإنتاج. انتظر حتى يكتمل.

2.  **تشغيل المتجر (وضع الإنتاج):**
    ```powershell
    pnpm start
    ```
    *   ستلاحظ أن المتجر يعمل الآن بسرعة فائقة.

### **الخطوة 6: معاينة المتجر**
افتح متصفح الويب واذهب إلى:

👉 **[http://localhost:3000](http://localhost:3000)**

ستجد المتجر يعمل بكامل منتجاته وبياناته التجريبية.

## نصائح إضافية

*   **للتعديل على الكود:** إذا أردت التعديل على الكود ورؤية التغييرات مباشرة، استخدم أمر `pnpm dev` بدلاً من `pnpm start`. لكن تذكر أن `pnpm dev` أبطأ في التحميل الأولي.
*   **النسخ الاحتياطي:** قم بأخذ نسخة احتياطية من قاعدة البيانات وملفات المشروع بشكل دوري.

إذا واجهتك أي مشكلة، لا تتردد في طلب المساعدة!
